Holdings data quality on an asset manager’s SEC filings

Large asset managers report their US holdings to the SEC every quarter on Form 13F: positions, identifiers, share counts and values across several group entities. It is the same shape of data an investment data quality team works with every day.

Type
Independent project
Data
SEC Form 13F filings
Runs
Weekly, published
Focus
Controls, reconciliation

01The problem

Most checks on a report like this compare the total with last quarter. That catches a sudden jump. It does not catch an error that has been there every quarter, because a consistent error moves with the trend.

I wanted controls that would hold up in a regulated reporting team: each one with an owner, a severity and a runbook, run against real filings rather than toy data.

02What I built

  • 19 SQL controls run every week on Legal & General’s real 13F filings, each with an owner, a severity, a value-affected measure, an SLA and a triage runbook.
  • Exceptions flow into a review queue. Decisions are recorded in the repository and reviewed like code, and every run is kept, so the history is auditable.
  • An independent re-read with TrueSet reconciles what was loaded against what was filed.
  • A live dashboard on GitHub Pages, and a CSV star schema for Power BI.

03The result

reports checked in the first real run, 29 Oct 2026

4
quarters of one subsidiary counted inside its parent

One subsidiary’s holdings were counted inside its parent’s book for four quarters, between $67.9bn and $99.6bn per report. The error was consistent, so every quarter-on-quarter check passed. An entity-level control caught it.

Critical controls also flagged the original Q3 2024 report, which was one line short of its declared count. The filer corrected it with a same-day restatement. The point is earlier detection: both would be flagged on the day the report is filed.

Independent project built from public filings on SEC EDGAR. Not affiliated with or endorsed by Legal & General. An exception is an item for review, not a statement that a filing is wrong.
