# Iyanujesu Taiwo Akinyefa: portfolio

Data engineering, data quality, governance and analytics. Static site, no build step.

- `index.html`: home
- `work/`: all projects with filters, plus one page per case study
- `writing/`, `recognition.html`, `experience.html`
- `assets/site.css`, `assets/site.js`: shared styles and scripts

Run locally:

```bash
python3 -m http.server 8000
```

Then open http://localhost:8000.
